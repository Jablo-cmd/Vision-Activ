# Vision Activ — Security & POPIA Specification
**Status:** Authoritative draft | **Version:** 1.0 | **Date:** 3 October 2026
## Principles
Least privilege, defence in depth, database-enforced authorisation, secure defaults, auditable privileged actions and data minimisation.
## Controls
Authentication; organisation/role/function scoping; RLS; secure RPCs for sensitive rules; input validation; controlled grants; audit logging; secrets outside source control; safe errors; dependency/security review; backup/recovery.
## POPIA foundations
Use personal information for defined purposes, minimise collection, restrict access, maintain safeguards, define retention/deletion and support applicable data-subject rights and consent/legal-basis workflows. This is an engineering specification, not legal advice.
## Sensitive employee data
Performance, capability, learning and development records require appropriate visibility. Technical administration must not automatically imply unrestricted business-data access.
