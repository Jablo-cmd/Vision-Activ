## Navigation
### Home
Overview, priorities, RAG/early warnings, recent evidence and required actions.

### My Transformation
Passport, Performance, Capability, Development, Academy, PICC, Achievements.

### Plan & Execute
Annual Goals, Quarterly Results, Monthly Results, Weekly Milestones, Daily Execution, Productive Hours.

### Performance
Weekly Performance Pulse, Monthly Performance & Growth Review, 12 Operating Protocols, Evidence & Verification, Corrective Actions.

### Capability & Academy
Skills, Capability Gaps, Development Plans, Academy Programmes, Learning, Assignments/Demonstrations, Badges, Certifications, Leadership Progression.

### Governance
Weekly Review, Monthly Review, Quarterly Review, Risks/Early Warnings, Decisions/Actions, Lessons Learned, Continuous Improvement.

### Organisation
Functional Performance, Client Delivery, Product & Technology Improvement, Innovation, Professional Work Discipline, Recognition, Executive Transformation Cockpit.

### Reports
Performance, Capability, Development, Academy effectiveness, Delivery, Transformation maturity, Governance, Organisational trends.

### Administration
People, Functions/Roles, Protocol standards, Academy content, Configuration, Notifications, Data governance, Audit.

## User journeys
Employee: Understand → Learn → Apply → Measure → Improve → Master → Sustain.

Manager: Plan → Monitor → Detect variance → Intervene → Verify → Review → Develop → Improve.

Executive: Direction → Performance → Risk → Capability → Governance → Decisions → Improvement.

## UX principle
Navigation follows how work happens, not database table names. Related workflows should be consolidated instead of exposing the underlying schema.
