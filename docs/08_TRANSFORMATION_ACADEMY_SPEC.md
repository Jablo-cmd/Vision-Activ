# Vision Activ — Transformation Academy Specification
**Status:** Authoritative draft | **Version:** 1.0 | **Date:** 3 October 2026

## Purpose
The Academy develops capability through understanding, application, demonstration and mastery. Attendance alone is not achievement.

## Pathways
1. Transformation Foundation
2. Operating Protocol Academy
3. Functional Capability Academy
4. Leadership & Mastery Academy

## Module standard
Metadata: programme, module, purpose, outcomes, protocol/skill, audience, content owner, version, approval, effective/review dates, assessment, pass requirement, badge and evidence rules.

Experience: assigned → current → due → progress → assessment → completed → badge/achievement → recommended next learning.

## Learning standard
Understand → See → Apply → Reflect → Assess → Practise → Demonstrate → Master.

## Assessment
Use knowledge, best-response/scenario, practical, system exercise, written response, evidence submission, workplace assignment or manager/facilitator verification as appropriate. A passing assessment demonstrates learning; sustained workplace application demonstrates mastery.

Failure path: feedback → review learning → practise → reassess.

## Governance
CEO/executive sets direction and certification philosophy. Functional Heads define capability requirements and verify application. Academy/Operations administers content, enrolment, assessment and records. Employees own participation and application.

## Content control
Version-controlled content has approval and effective dates. Standard changes trigger review of linked assessments, badges and evidence.
