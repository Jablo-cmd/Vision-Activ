# Vision Activ — Testing & Acceptance Specification
**Status:** Authoritative draft | **Version:** 1.0 | **Date:** 3 October 2026
## Layers
Typecheck/lint/build; unit; integration; database constraints/RLS; E2E; security regression; UAT; production smoke.
## Critical journeys
Authentication/scope; planning hierarchy; evidence/verification; variance/corrective action; weekly pulse; monthly self/manager review; capability gap/PICC/development; Academy learning/assessment/demonstration; Passport achievement; governance decision/action; executive reporting.
## Security acceptance
For every new/changed record path test authorised and unauthorised access, RLS, RPC permissions and direct-table access.
## Completion
No critical journey is complete while required tests, documentation or traceability are incomplete.
