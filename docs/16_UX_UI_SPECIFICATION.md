# Vision Activ — UX/UI Specification
**Status:** Authoritative draft | **Version:** 1.0 | **Date:** 3 October 2026
## Direction
Friendly, professional corporate blue-and-white. Serious transformation operating system, not a generic scorecard.
## Principles
Outcome-first; progressive disclosure; clear status; evidence near decisions; minimal duplicate entry; responsive; accessible; consistent terminology.
## States
Every workflow must handle loading, empty, validation error, permission denied, failure, draft, submitted/in-review and terminal states where applicable.
## UX rules
Navigation follows work, not tables. Forms use explicit labels and validation. Dashboards show what needs attention, why, owner, deadline and next action. Avoid score-only dashboards.
