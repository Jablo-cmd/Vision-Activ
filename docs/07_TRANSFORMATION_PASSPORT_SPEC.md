# Vision Activ — Transformation Passport Specification
**Status:** Authoritative draft | **Version:** 1.0 | **Date:** 3 October 2026

## Purpose
The Passport is the living individual record of transformation, capability, performance, learning, achievement and readiness.

## Required profile
Identity, role, function, Functional Head, leadership path and active status.

## Transformation record
Latest and historical protocol profile; planning/delivery history; evidence; capability requirements and demonstrated capability; gaps; development; Academy learning; badges; certifications; PICC; recognition; leadership progression.

## Rules
- Passport values are derived from authoritative domain records where possible.
- Historical achievements remain traceable to source evidence.
- Current state and historical state are distinguishable.
- Employees can maintain permitted self-service fields but cannot self-verify controlled achievements.
- Sensitive information follows role-based visibility and data-governance rules.

## Passport experience
Show current position, strengths, active gaps, active development, current learning, recent achievements, next actions and progression evidence. Avoid reducing the person to a single score.
